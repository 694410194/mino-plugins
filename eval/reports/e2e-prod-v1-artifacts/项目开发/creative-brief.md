# 短剧创作简报

## 1. 项目意图

- **暂定名**：《闪婚后傅总马甲藏不住了》
- **一句原始想法**：被家里逼着卖掉的私生女，在民政局门口随手跟一个"穷小子"闪婚，婚后才发现自己嫁的是藏着好几重马甲的大佬；而她自己也藏着一手没人知道的本事——两个人一路互相试探、互相打脸旁人，也慢慢摘掉彼此的伪装。
- **这次要完成的工作**：系列开发 + 分集规划（先落地前 5 集分集大纲）
- **来源材料**：无，原创想法（创作者口述题材：女频甜宠 + 马甲打脸；竖屏微短剧；60 集；单集约 90 秒）
- **不可更改的来源事实**：
  - 题材为女频甜宠 + 马甲打脸 → 落在 EP001–EP005，观众看到的是：先婚后爱的关系推进+当众打脸旁人；后续全程延续。
  - 60 集竖屏微短剧、单集目标 90 秒 → 全集形式约束，落在项目配置（format）。
  - 主要冲突线是"两个人都藏着身份，互相试探" → 落在 EP001 起，观众看到的是：领证时的交易条件、EP004–005 的身份怀疑。
- **允许改编/探索的范围**：人物姓名、具体职业与身份马甲的层数、打脸对象与场合、甜度与节奏、结局走向，均可探索。
- **原著没有、本轮新增的内容**：暂无（原创项目，无原著）。

## 2. 创作者契约

- **希望观众反复获得的体验**：爽——被看不起的人当场翻盘；甜——强势一方把偏爱给到明面上；悬——两个人各藏一手，谁先露馅。
- **不希望作品变成什么**：不想变成只有误会和解释的拉扯剧；不想让财富自动等于人格高下；不想让女主只负责被救。
- **主题张力**：被安排的关系 ↔ 自己挣来的选择；维持伪装的安全 ↔ 交心的代价。
- **语气与尺度**：轻快、甜、爽，情绪浓度高；冲突激烈但不阴郁；无过度暴力与露骨内容。
- **结局承诺或禁区**：走向团圆 HE（双向坦白、两重身份都被对方接住）；不写 BE，不用"其实他一直爱你"抹掉已发生的伤害。
- **内容边界**：不涉及真实品牌与真实人物；家族商战点到为止，不渲染违法手段细节。

## 3. 形式与制作边界

- **主要语言**：中文（普通话）
- **画幅/观看场景**：竖屏 9:16，手机端连续追更
- **单集与系列形式**：60 集，单集目标 90 秒；每集一个局部结果 + 集尾钩
- **可用角色与场景规模**：核心角色 6–8 人，场景以少数高辨识度空间反复复用（民政局、苏家客厅、傅氏大厦、傅家宅邸/家宴厅、医院走廊、车内）。宴会类大场面控制次数。
- **难以承受的制作元素**：大规模群演、频繁换景、复杂特效、真实豪车/豪宅实拍依赖
- **必须保留的视觉/声音特征**：断柄玉佩（女主身份信物）、"Y"黑卡、"代号 N"设计稿的暗记、"傅总"称谓与身份反差

## 4. 戏剧承诺（工作版）

- **焦点人物**：苏念——被苏家当佣人使唤、又被逼着卖掉的私生女，真身是三年前隐退的国际珠宝设计师"代号 N"。
- **当前追求**：先救重病的母亲，再拿回属于自己的名字与作品；日常层面是"借一段闪婚挡住苏家的买卖"。
- **昂贵阻力**：苏家（继母陈慧、父亲苏振国）握着她母亲的医药与旧账；同父异母妹妹苏曼偷了她的设计成名，步步踩她；傅家名媛林薇与傅家长辈看不起她的出身。
- **独特矛盾**：她越是用真本事自证，越可能暴露"代号 N"，把三年前那场大火和抄袭旧账一起翻出来；她越是依赖"穷老公"傅砚深出头，越无法确认自己嫁的到底是谁。
- **反复回报**：每一阶段观众都能看到一次"被看轻的人当场翻盘"，以及一次两人权力/信任位置的可见位移。
- **终止性转变**：两人各自的核心马甲向对方坦白并被接住，旧有的"试探—伪装"回路无法继续，故事进入共同面对外界的新阶段。

**一句工作陈述**：

> 苏念为了救母、为了不再被苏家卖，随手跟一个自称"小职员"的男人领了证；她以为自己在借一个挡箭牌，其实挡箭牌是藏着多重身份的傅砚深；两人各藏一手、互相试探，一路把苏曼、林薇和看不起她的人当众打回去，也在一次次并肩里，慢慢把伪装摘给对方看。

## 5. 方向候选与选择

> 题材已明确，不制造伪候选；记录选定方向的机制。

### 候选：双马甲闪婚（选定）

- 主角惯常策略：隐藏真本事、示弱换空间、把关系写进"协议条款"、在关键场合用作品/证据说话。
- 主要对抗机制：掌握她软肋的苏家（卖婚、医药费、旧账）+ 偷她设计的苏曼 + 门第偏见与名媛林薇；傅砚深一侧是家族继承压力与"不能暴露身份"的自我约束。
- 退出成本：母亲的命、自己的名声、以及一旦离婚就失去对苏家的挡箭牌。
- 反复回报：打脸（旁人被当场翻盘）+ 甜（偏爱摆到明面）+ 悬（谁先露馅）。
- 核心代价：越自证越接近暴露旧身份；越依赖对方越难确认彼此。
- 引擎终止条件：两重身份互相坦白并被接住。
- 主要制作负担：少量高识别空间复用；家宴/公开场合次数受控。
- 擅长提供：强钩子、强情绪落点、连续追更动力。
- 会牺牲：慢热写实感、复杂群像。

### 创作者选择

- **选定/组合**：双马甲闪婚（女主藏"代号 N"，男主藏"傅氏总裁/Y 先生/当年被救者"）。
- **选择理由**：最贴"马甲打脸 + 甜宠"，且天然提供信息权限差与身份悬念。
- **明确拒绝的方向**：单方苦情受害者线（女主只被救）、纯误会拉扯剧。
- **仍待确认的分支**：男主马甲具体几层、结局是否公开身份、甜度尺度的最终拿捏。

## 6. 核心人物与关系压力

### 苏念（女主）

- 当前目标/意识到的追求：救母亲、摆脱苏家的买卖、重回设计圈。
- 保护对象/不可失去之物：病重的母亲、母亲留下的断柄玉佩与设计手稿。
- 被捍卫的信念："本事是自己的，谁也偷不走；我可以示弱，但不能认输。"
- 形成该信念的前史成因：三年前作品被苏曼窃取、又遭一场大火，她带着伤隐退，学会把锋芒藏在低处。
- 惯常策略与优势：低姿态降低防备、关键时刻用作品/证据一击命中。
- 策略盲区与代价：习惯独自扛，不肯求助，容易把自己逼到死角。
- 可用筹码：真才实学（代号 N 的设计能力）、闪婚带来的"傅太太"身份、旁人对她的低估。
- 底线与可能越线条件：可忍羞辱，不可忍母亲受威胁；被逼到母亲安危时会亮底牌。
- 可能改变其策略的事实：发现傅砚深并非普通人 / 被傅砚深当众护住。

### 傅砚深（男主）

- 当前目标/意识到的追求：找到三年前救自己的女孩；在家族压力下守住自己的选择权。
- 保护对象/不可失去之物：傅氏的控制权、爷爷的信任、以及"被真心对待"的可能。
- 被捍卫的信念："我要的是冲我这个人来的，不是冲傅家来的。"
- 形成该信念的前史成因：多年被围绕财富的关系消耗；三年前车祸被一个陌生女孩所救，成了他心里唯一干净的记忆。
- 惯常策略与优势：用"穷小子/小职员"身份筛人、暗中掌控资源。
- 策略盲区与代价：隐瞒越深，越难被真正信任；保护手段容易被解读为控制。
- 可用筹码：傅氏资源、Y 先生资本、信息与权力网络。
- 底线与可能越线条件：可容她隐瞒，不容她受伤害；一旦她涉险会不惜暴露身份。
- 可能改变其策略的事实：确认苏念就是当年救他的人 / 苏念先对他坦白。

### 核心关系：苏念 ↔ 傅砚深

- A 需要 B / 害怕 B 看见 / 用来约束 B 的东西：苏念需要这段婚姻当挡箭牌，害怕他看见自己"代号 N"的旧事，用"三个月协议、互不干涉"约束他。
- B 需要 A / 害怕 A 拿走 / 用来反制 A 的东西：傅砚深需要她这份"不图钱"的靠近，害怕她知道真相后离开，用"别问我的过去"作条件。
- 当前不平衡：两人都在信息上占对方便宜，谁先坦白谁先失去安全感。
- 可能发生的关系状态变化：交易婚姻 → 互相护短 → 双向坦白 → 并肩。

## 7. 叙事切入窗口与前史储备

- **故事切入前已经运行的压力**：苏家已把苏念许给债主抵债、母亲手术费欠着；傅砚深被爷爷以继承权逼婚。
- **叙事切入窗口**：民政局门口，两个人同时被逼到墙角、必须当天做决定的那一刻。
- **第 1 集入口候选**：
  - **时序入口**：苏念在医院照顾母亲、被继母通知"明天去相亲还债"。——开场画面是病房与催款单；问题弱，收益慢，舍弃。
  - **收益入口（选用）**：民政局门口，苏念抢回被继母夺走的户口本、撞进同样攥着户口本的男人怀里。开场第一帧：两只手同时死攥着户口本、身后有人追。问题："这两个被逼到墙角的人为什么在这里结婚？"整集收益：一场三分钟闪婚 + 交易条款 + 男主身份反差的第一次漏光。
  - **冷开入口**：先放后文家宴上苏念被当众羞辱、傅砚深起身护她的最后一拍，再回民政局。可作为备选，但会把"家宴打脸"的爽点提前花掉，暂不采用。
- **为什么不更早/更晚开始**：更早会变成苏家日常的铺垫；更晚会丢掉"闪婚"这个决定本身的戏剧性。
- **开场可见证据**：两只死攥的户口本、追人的继母妹妹、男人袖口的定制表、门外黑色迈巴赫。
- **观众现在必须知道**：苏念是谁、被什么压着、要什么（救母、摆脱卖婚、重回设计圈）。
- **观众暂时不需要知道**：苏念=代号 N 的全部旧事；傅砚深全部马甲；三年前大火与车祸的关联。

## 8. 成功条件与待确认项

- **本轮产物必须保住的创作者选择**：双马甲、甜宠打脸基调、60 集/90 秒竖屏形式、HE 走向。
- **可以由后续单集继续发现的空白**：男主马甲层数与揭示节奏、具体打脸对象排序、结局公开程度。
- **若不确认会改变故事方向的问题**：
  - 男主最终是否公开身份、以什么方式公开？（影响后段高潮设计）
  - 苏念"代号 N"要不要在中期就半公开？（影响打脸强度与悬念长度）
- **不会阻止继续工作的次要未知项**：配角姓名细节、部分场景美术。
