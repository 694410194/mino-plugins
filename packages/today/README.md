# mino-today

侧边栏多一个「今日」图标：把助理一天的动态、定时任务、记忆和日记收进一个页面。

## 三个标签

| 标签 | 内容 | 数据从哪来 |
|---|---|---|
| **今日** | 定时任务的下次执行与状态 + 动态卡片（做完的事、值得留意的事、随手记） | 任务实时读宿主调度服务；动态是本插件自己的存储 |
| **记忆** | 「鱼的记忆」插件记下的事：长期记得的 + 慢慢变淡的（带鲜活度） | 直接读 fish-memory 自己的 `/dsh-fish-memory/list`；没装那个插件时显示安装提示，不报错 |
| **日记** | 按天归档的日记，可手补、可删 | 本插件自己的存储（`~/.mino/mino-today/store.json`） |

## 模型也能往里写

注册了两个工具，对话里自然触发：

- `today_post` —— 做完值得让她看到结果的事，投一张卡片到「今日」页；
- `diary_write` —— 往某天日记里写一条。

也可以在页面上手动「记一条」动态、「写一条」日记。

## 装法

```
dsh plugin --profile <name> add mino-today
```

或者从 Mino 插件市场安装。存储位置：`$DSH_HOME/mino-today/store.json`（Mino 下即 `~/.mino/mino-today/`）。
