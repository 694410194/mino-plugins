# 文风指纹模仿

不是"写得像一点"——是先量出指纹，再照指纹写。本方法在真实爆款口播稿上验证过（123 段样本 → 双稿对照 → 定稿）。

## 步骤

### 1. 拿样本或文风卡

- **文风卡**（content-factory/resource/styles/ 下的 `.md`）：已经是结构化画像，直接当指纹用，跳过第 2 步。卡的格式见 `references/persona-template.md`（上游 perfectly-replicate-writing-skills，MIT）。
- **原始样本**：视频样本走 `$video-breakdown` 的 ASR；图文样本直接用原文。样本要足量（≥100 段/句），不够就如实说明指纹不可靠。

### 2. 量文风指纹（全部出真数）

结构化画像的完整维度框架见 `references/7-dimensions-framework.md`（词汇/句法/语气/篇章/修辞/情感/视角 + 格式适配，上游 MIT 验证框架）；14 种成稿结构公式见 `references/writing-formulas.md`。快速版按下述清单量：

- **句/段长分布**：总数、均值、中位、最短最长、≤5字/6-12/13-20/>20 各档计数
- **语速**（口播样本）：总字数 ÷ 总时长，实测锚点 425 字/分
- **句式**：断句堆叠还是长句；口语连接词清单（那/然后/接着/但说实话）vs 书面连接词（首先/随后/综上所述/值得注意的是）
- **数字密度**：具体数字出现次数、出现位置
- **结构技巧**：逐条列并附样本原句——结果前置、结论前置、过程即内容、自曝边界、对立锚点等

### 3. 双稿对照写作

- **草稿 A**：常规写法写一稿（通常自带 AI 味），保留当对照
- **定稿**：按指纹改写——句长压到样本中位档、连接词换样本的口语套、数字只许用可溯源的真数、必须有自曝边界和具体立场句
- 两稿并排交付，不许只给定稿

### 4. 去 AI 味

过 `$humanizer-zh`，或按下表逐条自查（实测病灶清单）：

| AI 味病灶 | 处理 |
|---|---|
| 宏大开头"在当今…飞速发展的时代" | 删，第一句直给结果 |
| 书面连接词：首先/随后/综上/值得注意的是 | 换口语：那/然后/接着/但说实话 |
| 套话升华"提供了全新可能性" | 换成具体立场句 |
| 无主语流程腔"进行了系统性的拆解" | 加主语+动作细节："ffmpeg 扫了 24 个切点" |
| 抽象名词堆"范式/图谱/赋能" | 具象化到可数物："13 段能照着抄的结构" |
| 不敢下结论"出现了一定偏差" | 直接判定+证据："听成了废物，写稿必须换大模型" |
| 无数字"先进的算法" | 塞真数（实测定稿 14 处：26.9兆/24切点/40帧） |
| 无对手戏 | 加对立锚点："大家还在讨论是不是团队精修" |
| 无自曝边界 | 明说没验什么："还差两块，没显卡验不了" |
| 长句（均 ~35 字） | 压到中位 ~13 字，断句堆叠 |

## 验收闸

- 指纹全部真数、附统计，不许拿"语感像"当指纹
- 定稿每个数字都能指回素材/事实；新增数字零容忍
- 事实、确定程度、归因不被文风改写吞掉（与 `$humanizer-zh` 第一约束一致：不增事实、不丢独立信息、不把可能改成确定）
- 草稿 A 与定稿并排交付，修改可逐条指认
