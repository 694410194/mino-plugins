# 视频拆解 — 对标片 → 复刻配方

把一条成片视频拆成可直接照抄的结构配方。本方法在 224s 真实爆款口播混剪片上端到端验证过（24 切点 + 40 帧 contact sheet + 123 段 ASR → 13 段结构）。

## 前置

- 视频文件已在本地（抓取不在本 skill 范围）
- `ffmpeg` 可用
- ASR：`pip install faster-whisper`（CPU 跑 small/int8 即可）

## 步骤

### 1. 场景检测定硬切点

```bash
ffmpeg -i src.mp4 -vf "select='gt(scene,0.4)',showinfo" -f null - 2>&1 | grep showinfo | grep -oE "pts_time:[0-9.]+"
```

得到全部硬切时间戳（实测 224s 片检出 24 个）。软切/叠化会漏检，靠下一步 contact sheet 补。

### 2. 等间隔 contact sheet

```bash
ffmpeg -i src.mp4 -vf "fps=1/<间隔>,scale=320:-1,tile=8x5" contact.jpg
```

间隔按片长取 `片长/40` 左右，保证 40 格铺满全片。逐格过一遍：补场景检测漏掉的软切，标注每格的内容类型，帧号 × 间隔即可回推时间戳。

### 3. ASR 逐字稿

```bash
python scripts/transcribe.py <视频路径> [输出json]
```

faster-whisper small + word timestamps + VAD。

**硬规则**：小模型听品牌词必翻车（实测：Fable→"废物"、ChatGPT→"拆得起"、Opus→"OBUS"）。

- 转写稿只做**定位+结构**用途
- 品牌/专名听不准的标 `（估）` 或 `?`，不猜实义
- 要发布/配音/复用的文本必须换大模型转写或人工逐条校正

### 4. 逐镜分类 + 分镜表

按切点 + contact sheet 逐镜记：时间段 / 类型（口播·录屏·MG卡·大字overlay·B-roll·实拍）/ 内容 / 节奏功能。连续同功能镜头合并为"段"。

### 5. 提取配方（交付物）

- **结构公式**：段序列模板，如「冷启动直给(最强结果 0-10s) → 语境+对立面 → 官方背书 → 自曝边界转场 → 总评金句前置 → Case 弱→强递进 → 第三方核验 → 成本收尾 → 固定收尾」
- **节奏参数**：平均镜头时长（真数，实测锚点 ~2.8s）、口播句时长、转场手法、punch 点位置与全片频次
- **字幕样式**：位置 / 单行字数 / 样式
- **叙事技巧**：逐条列——结果前置、结论前置、过程即内容、自曝边界、对立锚点等
- **替换变量**：换皮只换什么（产品名/case素材/结论），什么不动（结构/节奏/卡位）——这就是"模板=SOP"的含义

## 验收闸

- 分镜表每行有时间戳+类型，无"待确认"段
- 节奏参数是真数，不是"较快/适中"
- 结构公式能让没看过原片的人复述出来
- 替换变量清单闭环：每个变量都标了对应原片位置
