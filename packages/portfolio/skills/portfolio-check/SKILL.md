# 行情与持仓盘点

公共行情接口查价，持仓在用户本机算。

## 流程

1. **查价**：`market_quote` 传代码列表。用户说名字不给代码时，先问代码或给常见代码让用户确认——不要猜代码。
2. **持仓**：`market_portfolio` 传 holdings 或 CSV 文件路径。用户没整理过持仓就帮他先列一份（代码/股数/成本），存成 CSV 以后直接用。

## 注意

- 行情是参考价：股票是实时/准实时报价，基金是盘中估值（fundgz），收盘以官方净值为准。
- 持仓数据不出本机——只有证券代码发给公共行情接口，股数/成本不离开。
- 不给投资建议：报数字、算比例可以；不要替用户说"该买该卖"。
