# mino-connector-portfolio

行情与持仓连接器。查股票/基金实时价，算自己持仓的盈亏。

## 原则

- **本地**：持仓数量、成本只在本机算，不出本机。
- **最小暴露**：公共行情接口只收到证券代码（本身不是个人信息）。
- **用户主动**：持仓清单你自己给（参数或 CSV 文件）。

## 工具

| 工具 | 说明 |
|---|---|
| `market_quote` | 批量查价：`codes` 支持 `600519`/`sz000001`/`bj430047`/基金 `110022` |
| `market_portfolio` | 持仓盈亏：`holdings [{code,shares,cost}]` 或 `file` CSV 路径 |

行情源：腾讯 qt.gtimg.cn（股票）、东方财富 fundgz（基金估值）。
股票实时/准实时，基金是盘中估值，收盘以官方净值为准。
