# 年度聊天回顾

用本域连接器把今年和谁聊了什么整理成一份年度总结。数据全程本地，产物写用户目录。

## 流程

1. **确认数据**：相关工具（chat_search 按 sender/时间统计）有数据才做；没有先引导导入。
2. **取数**：调对应工具拉统计和明细。
3. **写报告**：在数据同目录写 `<年份>-chat报告.md`，结构：
   - 总览（区间/总量/来源）
   - 聊天总量、最常聊的人 TOP、年度高频词
   - 值得记住的几条（选有故事感的明细）
   - 结语一句

## 纪律

- 数字必须来自工具返回，不估不编
- 数据缺口直说，不补假数
