# 找文件

按文件名在用户本机检索。只按名字找，不读内容；找到后要不要打开看用户说了算。

## 流程

1. `files_search` 传文件名关键词。用户说了盘符/目录就传 root（比如"D:\\"）。
2. 没结果就换近义词/截短关键词再来一次（"毕业论文终稿"→"毕业"→"论文"）。
3. 找到多个就按修改时间和路径帮用户挑，列给用户看，不替他删、不替他移。

## 注意

- 全盘秒搜需要用户装了 [Everything](https://www.voidtools.com/)（装了就自动走它）；没装兜底只扫 桌面/下载/文档/图片/视频，找不到时提醒用户可以装 Everything 或给 root 目录。
- 按内容找（"里面有 xxx 字样的文件"）不是这个 skill 的事——文件名找到候选后用文件读取工具看内容。
