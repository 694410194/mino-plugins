# 上网足迹回顾

只读本机浏览器历史，帮用户找回看过的页面、盘点上网习惯。全本地处理。

## 流程

1. **定位库**：默认 auto 选最近有记录的浏览器；用户说清用哪个就传 browser=chrome/edge/firefox/brave。
2. **找回网页**：`browser_history_recent` 配 q 关键词（比如"那个讲 sqlite 的页面"→ q=sqlite）。找得到就给标题+链接，找不到就换近义词再试，别一次放弃。
3. **习惯盘点**：`browser_history_top` 按 days 统计常去站点，结合 recent 看最近一周在看什么。

## 回顾报告（用户要求盘点时产出）

```markdown
# 上网足迹回顾

## 常去站点 TOP10（近 N 天）
- 站点：次数

## 最近在关注什么
- 按标题/域名归纳 3-5 个主题线，举例页面

## 值得收藏的页面
- 访问多次但没收藏的（访问次数高的具体页）

## 观察
- 一两条白话观察（比如时间分布、习惯变化），不写教条的
```

## 注意

- 这是**用户自己机器上的记录**，不是上网监控——只回答用户问的，不主动翻无关记录。
- 浏览器开着也能读（先复制快照再查）；读不到库时提示用户确认浏览器装没装、或让用户自己给库文件路径（path 参数）。
- 历史里没有正文内容——要找"页面上写了什么"得拿到链接后再去打开。
