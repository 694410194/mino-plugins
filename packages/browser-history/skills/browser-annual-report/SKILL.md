# 浏览器年度足迹

用本域连接器把你一年里在浏览器上看了什么整理成一份年度总结。数据全程本地，产物写用户目录。

## 流程

1. **确认数据**：相关工具（browser_history 按月/域统计）有数据才做；没有先引导导入。
2. **取数**：调对应工具拉统计和明细。
3. **写报告**：在数据同目录写 `<年份>-browser报告.md`，结构：
   - 总览（区间/总量/来源）
   - 访问最多的站点 TOP、按月的活跃曲线、深夜浏览占比、值得回看的页面
   - 值得记住的几条（选有故事感的明细）
   - 结语一句

## 纪律

- 数字必须来自工具返回，不估不编
- 数据缺口直说，不补假数
