# 海报设计规范

目标：**一张让人愿意截图/转发的竖版海报**。先写自包含 HTML，再 `poster_render` 出 PNG。

## 版式（默认 750×1334）

- 顶部：一句人话标题（如「你这一年，钱花在了哪」）+ 年份角标
- 大数字区：3 个以内关键数字，巨大字号（80-140px），配一句人话解读
- 榜单/排行区：TOP 5-8 条形榜或列表，每条一行不超 20 字
- 一个「有意思的细节」区块：挑最有故事感的一条明细单独呈现
- 底部：数据区间 + 来源（「数据：本地语料，未出本机」）+ Mino 署名小字

## 审美纪律

- **自包含**：所有 CSS/SVG 内联，禁止外部图片/字体/CDN（断网也要能渲染）
- 配色一套主色 + 灰阶：深蓝/墨绿/暖橙任选其一做主色，别彩虹
- 字体栈：`"PingFang SC","Microsoft YaHei",sans-serif`；数字可用 `Georgia,serif`
- 大留白：padding ≥40px，元素间距 ≥24px；圆角卡片 12-16px，轻阴影
- 数据必须来自工具返回的真实数字，**不许编**；没有的数据直接不写
- 中文字号下限 14px，重要数字加粗
- 一句结语放最下（轻、短、有温度）

## 流程

1. 从对应连接器/年报 skill 拿到真实数据
2. 按上面版式写 HTML（整体 `width:750px; margin:0 auto`）
3. `poster_render` 出 PNG，把路径给用户
4. 想改图就改 HTML 重渲
