# 账单年度报告

把用户自己导出的支付宝/微信账单文件整理成一份年度消费报告。
全程本地处理，原始数据不出本机；只向用户要文件路径，不替用户找文件。

## 流程

0. **可选出图**：把报告要点按 `poster-design` 技能写成自包含 HTML，调 `poster_render` 出 PNG 晒图。

1. **收集文件**：问用户账单导出文件放在哪（支付宝：我的→账单→右上角→开具交易流水证明→用于个人对账；微信：我→服务→钱包→账单→右上角→下载账单→用于个人对账）。可多份、跨年混合。
2. **逐份解析**：对每个文件调 `bills_import`（provider 留 auto 即可）。记下每份产物路径与返回汇总。
3. **合并口径**：多个文件的 months/topCategories 逐项相加；重复记录（同一交易号跨文件）提醒用户可能重复，不要擅自去重删数据。
4. **产出报告**：在账单所在目录写 `<年份>-消费报告.md`，结构如下。

## 报告模板

```markdown
# <年份> 消费报告

## 总览
- 统计区间 / 总支出 / 总收入 / 月均支出 / 数据来源（哪几份文件）

## 钱花在什么上
- 支出分类 TOP10 表（类别、金额、占比）
- 与上年的可比变化（若有多份数据）

## 大额与异常
- 单笔大额 TOP10（日期、去向、金额）
- 未分类条目数及建议（需要补规则的类别）

## 订阅与固定支出
- 月度固定扣款项识别（同 payee 多笔同额）

## 月度走势
- 每月支出曲线表；峰值月份归因（哪个分类拉的）

## 建议
- 基于数据的 3-5 条白话建议，不写空话
```

## 注意

- 数据缺口明说（比如只有 8 个月、只有支付宝没有微信），不要脑补。
- 未分类条目多（FIXME）时提示用户：可以写自定义分类规则传给 bills_import 的 rules 参数。
- 报告写完把路径交给用户，不替用户上传或外发。
