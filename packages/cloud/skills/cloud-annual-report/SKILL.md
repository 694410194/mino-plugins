# 云端年度盘点

用本域连接器把各云源账号里的积累整理成一份年度总结。数据全程本地，产物写用户目录。

## 流程

1. **确认数据**：相关工具（cloud_list/cloud_pull 各源明细）有数据才做；没有先引导导入。
2. **取数**：调对应工具拉统计和明细。
3. **写报告**：在数据同目录写 `<年份>-cloud报告.md`，结构：
   - 总览（区间/总量/来源）
   - 收藏量、网盘占用、关注内容主题分布
   - 值得记住的几条（选有故事感的明细）
   - 结语一句

## 纪律

- 数字必须来自工具返回，不估不编
- 数据缺口直说，不补假数
