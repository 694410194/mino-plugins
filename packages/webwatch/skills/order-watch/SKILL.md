# 被动观察

有的域没有官方导出也爬不动（12306/滴滴/拼多多订单）。但用户自己在浏览器里
打开过这些页面——**历史记录就是入口**。

## 流程

1. 用户说「帮我整理订单/行程」「查我最近买了啥」而对应域没有活通道时：
   `watch_scan` 扫浏览器历史命中订单/行程页
2. 命中后按每条的 `hint` 走导入通道：
   - 页面内可全选复制 → 喂 `connector-orders` / `connector-travel`
   - 只有截图 → 喂 `connector-ocr`
   - 有官方导出 → `connector-bills`（支付宝/微信/京东/美团账单官方导）
3. `watch_suggest` 给单个站点的完整通道说明

## 口径

- 只读用户本机浏览器历史库（快照复制后只读打开），不监听、不驻留、不上传
- v0 是「检测到访问过 → 给导入通道」，不做实时页面监听
- 导入动作始终由用户发起/确认，不替用户抓取页面内容
