# 备份年度体检

用本域连接器把备份够不够整理成一份年度总结。数据全程本地，产物写用户目录。

## 流程

0. **可选出图**：把报告要点按 `poster-design` 技能写成自包含 HTML，调 `poster_render` 出 PNG 晒图。

1. **确认数据**：相关工具（backup_dirs/backup_itunes）有数据才做；没有先引导导入。
2. **取数**：调对应工具拉统计和明细。
3. **写报告**：在数据同目录写 `<年份>-backup报告.md`，结构：
   - 总览（区间/总量/来源）
   - 各设备最近备份时间、内容域分布、风险提示
   - 值得记住的几条（选有故事感的明细）
   - 结语一句

## 纪律

- 数字必须来自工具返回，不估不编
- 数据缺口直说，不补假数
